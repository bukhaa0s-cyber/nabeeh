# Nabeeh — store season kit

## The Mawhiba calendar (check the official site every year)
- The National Program for Gifted Identification opens registration around the **start of October** and tests run at Qiyas centres from about **early November to late December**.
- 2026–2027 cycle: registration 1–23 Oct 2026 (hail-talent.com calendar, program 17); the 2025 cycle tested 9 Nov – 25 Dec 2025 (ajel.sa, 10 Nov 2025).
- So the busy window for the app is **mid-September → end of December**. Prepare the store by **1 September** each year.

| When | What |
|---|---|
| 1 Sep | New screenshots and promotional text for the season; plan an In-App Event |
| 15 Sep | In-App Event "Registration season" goes live (runs to the close of registration) |
| 1 Oct – 25 Oct | Apple Search Ads, small daily budget, on the keyword list below |
| 1 Nov – 25 Dec | In-App Event "Final-week practice"; promo text about the test-week plan |
| January | Promo text switches to the puzzle of the day and next year |

**English — after the season**

## In-App Events (name ≤ 30, short description ≤ 50, long description ≤ 120)
**Registration season** (badge: Challenge)
- AR name: موسم الاستعداد للموهوبين — short: ابدأ التدريب مع فتح التسجيل
- AR long: اختبار تجريبي بتوقيت حقيقي، وخطة يومية حتى موعد الاختبار، ودروس قصيرة لكل نوع سؤال.
- EN name: Gifted test season — short: Start practising as registration opens
- EN long: A real-timing mock test, a daily plan up to test day, and a short lesson for every question type.

**Final week** (badge: Special Event)
- AR name: الأسبوع الأخير قبل الاختبار — short: مراجعة الأخطاء وتحدي السرعة
- AR long: خطة الأسبوع الأخير: اختبار كل يومين، مراجعة دفتر الأخطاء، ونصائح ليلة الاختبار ويومه.
- EN name: The final week — short: Mistake review and a speed challenge
- EN long: The final-week plan: a mock test every two days, notebook review, and tips for the eve and the day.

Each event needs a 1920×1080 card image and a 3:4 or 9:16 video/image; make them from the app's colours and the owl.

## Apple Search Ads
Start with Search Ads Basic or Advanced on a small daily cap during 1–25 Oct only. Target: the Arabic keywords above plus "تدريب موهبة", "اختبار موهبة", "مقياس موهبة". Stop if cost per install is above the value of the ads a user sees in a month.
